    API reference

    Client

    Provider-agnostic entry point: same API regardless of backend.

    Requests are retried at most once. Connect errors, connect timeouts and 429 responses are retried for any request; read/write timeouts, 500/502/503/504 responses and other request errors only for idempotent requests. A Retry-After header is honoured, capped at 10 seconds. Capabilities a provider lacks raise NotSupported.

    __init__(provider, api_key, *, webhook_secret=None, webhook_max_age=_UNSET, timeout=30.0)

    Create a client for one provider.

    Parameters:

    Name Type Description Default
    provider str

    Provider name, "vapi" or "retell".

    		 required
    api_key str

    The provider API key.

    		 required
    webhook_secret str | None

    Secret used to verify webhooks. Retell falls back to the API key when omitted.

    		 None
    webhook_max_age float | None | _Unset

    Retell only. Max webhook signature age in seconds (default 300); None disables the replay check.

    		 _UNSET
    timeout float

    Per-request HTTP timeout in seconds.

    		 30.0

    Raises:

    Type Description
    ValueError

    If the provider name is unknown.
    NotSupported

    If webhook_max_age is passed for Vapi.

    from_env(provider=None, *, environ=None, **overrides) classmethod

    Build a client from environment variables.

    Reads VOICE_PROVIDER (unless provider is given), then

    _API_KEY,

    _WEBHOOK_SECRET and

    _WEBHOOK_MAX_AGE where

    is the upper-cased provider name. Empty values count as unset.

    Parameters:

    Name Type Description Default
    provider str | None

    Provider name; defaults to VOICE_PROVIDER.

    		 None
    environ Mapping[str, str] | None

    Mapping to read instead of os.environ.

    		 None
    **overrides Any

    Keyword arguments for the constructor (api_key, webhook_secret, webhook_max_age, timeout); they win over environment values. With an api_key override,

    _API_KEY is not required.

    		 {}

    Raises:

    Type Description
    ValueError

    If the provider or API key is missing, or

    _WEBHOOK_MAX_AGE is not a number.

    NotSupported

    If

    _WEBHOOK_MAX_AGE is set for Vapi.

    create_call(agent_id, to_number, *, from_number=None)

    Start an outbound call.

    Parameters:

    Name Type Description Default
    agent_id str

    The agent that will handle the call.

    		 required
    to_number str

    Destination number in E.164 format.

    		 required
    from_number str | None

    Caller number; needed for outbound calls on both providers. Retell requires an E.164 number (ValueError if missing). On Vapi pass an E.164 number, looked up among your phone numbers, or a phone-number id.

    		 None

    Raises:

    Type Description
    ValueError

    On Retell, if from_number is missing.
    ProviderError

    On Vapi, if no phone number matches from_number.
